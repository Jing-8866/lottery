# 投注工具 — 号码生成算法说明

## 总体设计理念

模拟真实开奖号码的统计特征，不再是纯随机数。每次生成会从**多种策略中随机选择一种**，保证号码多样性。

```
多策略随机选择 → 过滤不合理号码（连号检查） → 保底纯随机
```

## 核心算法

### 1. 基础随机采样 `sample(min, max, count)`

Fisher-Yates 洗牌算法，从范围中无重复抽取 N 个数字，升序返回。

```
例：sample(1, 33, 6) → [3, 8, 15, 22, 26, 31]
```

### 2. 连号过滤 `hasTooManyConsecutive(nums)`

**规则**：4个及以上连号 → 拒绝；3连号 → 允许

```
[5, 6, 7, 8] → 拒绝（4连号）
[15, 16, 17] → 允许（3连号）
```

### 3. 权重随机抽取 `weightedPick(weights)`

按权重比例随机选一个下标。

```
weights = [10, 30, 60]
→ 下标0概率10%，下标1概率30%，下标2概率60%
```

## 号码生成策略（共8种）

### 走势策略（依赖历史数据）

#### 策略A：热号加权 `strategyHotWeighted`

- 分析最近80期历史数据中每个号码的出现频率
- 频率越高的号码，被选中的概率越大
- 从未出现的号码也有最低权重（+1），不会完全没机会

```
权重 = 出现次数 + 1
```

#### 策略B：冷号反弹 `strategyColdRebound`

- 计算每个号码的"冷热评分"：近期出现越少，评分越低
- 低于平均分的号码（冷号）获得反弹权重
- 越冷权重越大，模拟"冷号回补"现象

```
反弹权重 = 平均分 / (分数 + 1) × 10
```

#### 策略C：热冷混合 `strategyHotColdMix`

- 按冷热评分将所有号码分为"热号池"和"冷号池"
- 随机决定热号比例（40%~70%）
- 从热号池和冷号池分别抽取，合并排序

#### 策略D：近期趋势跟随 `strategyRecentTrend`

- 分析最近30期的**区间分布密度**
- 根据各区间的热度比例分配每区抽取数量
- 在各区间内使用热号加权策略抽取

### 传统统计策略（无历史数据也可用）

#### 策略1：区间分布法 `strategyZoneBalanced`

- 将号码范围分为 N 个区间（双色球=3区，快乐8=4区）
- **不强制均匀分配**，采用区间轮盘赌方式：
  - 每个号码独立分配到哪个区间，按**区间大小加权随机**
  - 区间大的（如 23-33 有11个号）被选到的概率更高
  - **允许某些区间多选、少选甚至不选**
- 例如双色球6红球+3区，可能产生 `[2, 3, 1]`、`[4, 0, 2]` 等灵活分布

#### 策略2：奇偶牵引法 `strategyParityDriven`

- 从配置的合法奇偶比中随机选一个（如 3:3、4:2）
- 分别从奇数和偶数池中抽取
- 合并排序，检查连号

#### 策略3：和值导向法 `strategySumGuided`

- 随机生成一组号码
- 检查和值是否在合理范围内
  - 双色球红球：80~140
  - 大乐透前区：50~120
  - 七乐彩基本号：80~150
- 不在范围则重试，最多15次

#### 策略4：跨度优先法 `strategySpanFirst`

- 先固定首尾号（跨度在合理范围内）
  - 双色球红球：18~30
  - 大乐透前区：18~32
- 在首尾号之间填充中间号码
- 保证号码有合理的离散度

### 兜底策略

所有策略失败时，直接调用 `sample()` 纯随机抽取。

## 智能选择引擎 `smartGenerate`

### 策略池权重分配

```
走势策略（有历史数据时）：
  热号加权       权重 4
  冷号反弹       权重 4
  热冷混合       权重 4
  近期趋势跟随   权重 4

传统策略（始终可用）：
  区间均匀分布   权重 3
  奇偶牵引法     权重 2
  和值导向法     权重 2
  跨度优先法     权重 1

兜底：
  纯随机采样     权重 1
```

每次生成时按权重随机选择一种策略。

### 流程

```
loadHistoryData(type) → 解析历史JSON数据
  ↓
analyzeFrequencies() → 各号码出现频率 Map
  ↓
analyzeColdHot() → 各号码冷热评分（近期加权）
  ↓
smartGenerate() → 随机选策略 → 生成号码 → 连号检查
  ↓
渲染为 HTML 球号显示
```

## 快乐8特殊处理

快乐8号码多（每期开20个号），连号是正常现象，因此：

- **不限制连号**
- 使用**四区间均匀分布**策略
- 可选走势版（有历史数据时使用 `smartGenerate`）

## 定位彩种（福彩3D/排列3/排列5/七星彩）

这类彩种每位数字独立随机 0-9，**数字可重复**，不使用上述策略：

```
for (let d = 0; d < count; d++) {
    digits.push(Math.floor(Math.random() * 10));
}
```

每个位置的数字相互独立，例如福彩3D可能生成 `[1, 1, 2]`（可重复）。
